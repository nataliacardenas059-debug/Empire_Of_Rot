# Descripción del juego

Empire Of Rot es un videojuego desarrollado en Java y JavaFX basado en un sistema de combate por turnos ambientado en un mundo postapocalíptico lleno de criaturas infectadas y enemigos peligrosos.

El jugador puede asignar un nombre a su personaje y escoger entre distintos tipos de combatientes, cada uno con habilidades y características únicas. Entre los roles disponibles se encuentran el Cazador, Arquero y Soldado, cada uno diseñado con estilos de combate diferentes.

Durante la partida, el jugador deberá enfrentarse a enemigos aleatorios como zombis, bestias e infectados, luchando uno a uno hasta lograr sobrevivir o ser derrotado. El videojuego cuenta con un sistema de combate funcional en el que el usuario puede:

- Atacar enemigos
- Utilizar habilidades especiales
- Recargar armas
- Huir de la partida

El sistema genera de manera aleatoria estadísticas como vida, daño y munición, haciendo que cada partida sea diferente y más dinámica. Además, se implementó un sistema de puntuación y un ranking Top 5 que almacena automáticamente los mejores puntajes utilizando archivos TXT.

El proyecto fue desarrollado aplicando conceptos de Programación Orientada a Objetos como:

- Herencia
- Polimorfismo
- Clases abstractas
- Interfaces
- Encapsulamiento
- Composición
- Sobrecarga de métodos
- Colecciones
- Manejo de archivos

La interfaz gráfica del videojuego fue desarrollada utilizando JavaFX, permitiendo una experiencia visual más interactiva y moderna.

# Instrucciones de instalación

## 1. Clonar repositorio

Abrir Git Bash o la terminal de comandos (CMD) y ejecutar el siguiente comando:

```bash
git clone https://github.com/nataliacardenas059-debug/Empire_Of_Rot.git
```

Después entrar a la carpeta del proyecto:

```bash
cd Empire_Of_Rot
```

---

## 2. Abrir proyecto en IntelliJ IDEA

- Abrir IntelliJ IDEA
- Seleccionar la opción **Open**
- Buscar y seleccionar la carpeta **Empire_Of_Rot**
- Esperar a que Maven descargue automáticamente las dependencias

---

## 3. Verificar configuración de JDK

El proyecto utiliza Java JDK 21.

En IntelliJ IDEA verificar:

File -> Project Structure -> Project SDK
```

Seleccionar:

JDK 21
```

---

## 4. Ejecutar el proyecto

Ejecutar la clase:

Launcher.java
